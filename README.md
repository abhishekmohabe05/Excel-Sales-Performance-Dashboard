# 📊 Sales Performance & Target Analysis Dashboard

## 📌 Project Overview

This project is an interactive **Sales Performance & Target Analysis Dashboard** developed using **Microsoft Excel**.

The dashboard helps analyze sales performance across different cities and sales executives by comparing actual sales with assigned targets.

## 🎯 Key Features

- 📈 Sales performance analysis
- 🎯 Target achievement percentage
- 📊 Away-from-target percentage
- 🏙️ City-wise performance analysis
- 👤 Sales executive-wise performance analysis
- 🔍 Interactive filtering
- 📉 Data visualization using charts
- ⚙️ VBA/Macros for dashboard interaction and automation

## 🛠️ Tools & Technologies

- Microsoft Excel
- VBA / Macros
- Data Analysis
- Data Visualization
- Dashboard Development

## 📊 Dashboard Insights

The dashboard provides an easy way to:

- Compare actual sales with targets
- Identify high-performing sales executives
- Analyze performance across different cities
- Identify executives who are above or below their targets
- Present sales data in an interactive and visual format
